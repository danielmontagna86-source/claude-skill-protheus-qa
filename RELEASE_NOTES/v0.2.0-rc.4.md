# 0.2.0-rc.4 — Instalação manual, instalação com IA e uso com IA

Esta atualização inclui os procedimentos no repositório e no pacote instalável:

- `INSTALL.md`: instalação por projeto em Windows, caminhos Claude Code/Codex, checksum, validação, descoberta, atualização e rollback.
- `INSTALL_WITH_AI.md`: prompt copiável para instalar sem acessar o ERP e roteiro separado para preparar runtime autorizado.
- `USAGE_WITH_AI.md`: primeiro uso, contexto mínimo e prompts de análise, regressão, geração offline, diagnóstico e consolidação de QA.

O README aponta diretamente para os três percursos. Os testes adicionais verificam links, contrato, argumentos CLI, bloqueio dos exemplos incompletos e inclusão dos guias no ZIP. Consulte os resultados efetivos do workflow desta revisão; este texto não presume aprovação de um job ainda não executado.

O motor de execução, o SKILL.md e a baseline TIR 2.14.10 não foram alterados. Continua uma pré-release de ferramentas, limitada a consulta autorizada em homologação. Instalar a skill não instala TIR e não autoriza abrir o ERP.

Os avisos de dependências permanecem sujeitos a revisão. Auditoria concluída não é aprovação de segurança. Não há homologação Protheus nem comprovação de descoberta em um cliente IA instalado na máquina do usuário.
